# ⏱️ Animated Countdown

A simple **Animated Countdown** project made using **HTML, CSS, and JavaScript**.

The project shows a countdown animation from **3 → 2 → 1 → 0** and then displays **GO**. A Replay button is provided to start the animation again.

## 🚀 Live Demo

👉 https://soumyadwippal.github.io/animeted-countdown/

## ✨ Features

* ⏱️ Animated countdown
* 🔢 Countdown from 3 to 0
* 🚀 Displays "GO" after the countdown
* 🔄 Replay button
* 🎨 Simple animation and design
* ⚡ Built with vanilla JavaScript

## 🛠️ Technologies Used

* HTML5
* CSS3
* JavaScript

### 2. Open the project folder

```bash
cd animeted-countdown
```

### 3. Run the project

Open `index.html` in your browser.
